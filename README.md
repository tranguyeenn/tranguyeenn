### [Cmdlet](https://github.com/tranguyeenn/cmdlet)
**macOS Command Palette | Rust · TypeScript · Tauri**

A lightweight, keyboard-driven desktop utility for executing commands without navigating through multiple applications.

- Built with Tauri 2, Rust, TypeScript, and Vite
- Global keyboard shortcut and command-based interface
- Finder integration for file operations
- File moving with destination aliases, conflict handling, and undo
- Designed around fast interactions and minimal overhead

### Shelftxt
**Book Recommendation System | Python · FastAPI**

A backend-oriented project for organizing and ranking books in a reading list.

- Book management and ranking logic
- API-based architecture
- Exploring personalized recommendation approaches

### Podify
**Spotify CLI Controller | Python · Spotify Web API**

A terminal-based tool for controlling Spotify playback.

- Keyboard-driven playback controls
- Spotify API integration through Spotipy
- Command-line interaction without a graphical interface
